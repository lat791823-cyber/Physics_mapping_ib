# Physics_mapping_ib

This repository now includes a biology-focused revision interface component:

- `src/BioRevisionApp.jsx`: IB Biology revision trainer with:
  - topic-based syllabus coverage
  - mixed-format practice prompts (MCQ, short response, data-style)
  - score tracking to identify strengths and weaknesses by topic

## Notes on content sourcing

The app is intentionally built for ethical and legal study use:

- No leaked exam content is included.
- No bulk copyrighted text from third-party revision websites is copied.
- Practice material is original and syllabus-aligned.
